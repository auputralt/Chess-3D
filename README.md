# Chess 3D 🏁

An interactive 3D chess game built with Three.js and vanilla JavaScript.

## Features

- Full 3D chess board visualization
- Interactive piece movement
- Game state management
- Responsive design

## How to Play

1. Open the game in a modern web browser
2. Click and drag to rotate the board view
3. Click on a piece to select it
4. Click on a valid square to move the piece

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Three.js for 3D rendering

## Development

This project is a simple single-page application with no build dependencies.
