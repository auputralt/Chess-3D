A beautiful, feature-rich 3D chess game built with pure JavaScript and Three.js. This project showcases a complete chess implementation with stunning visuals and smooth gameplay.

## 🎮 Game Features

### Core Gameplay
- **Full Chess Implementation**: Complete chess rules including all piece movements, castling, en passant, and pawn promotion
- **Two Modes**: Play against a friend (2-player) or challenge the AI
- **3D Visualization**: Beautiful 3D board with rendered chess pieces
- **Intuitive Controls**: Click to select, click to move interface

### Visual Features
- **Dark Theme**: Elegant dark board design with gold accents
- **Smooth Animations**: Fluid piece movements and board rotations
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **No Dependencies**: Pure HTML, CSS, and JavaScript - no external libraries needed

### User Interface
- **Game Timer**: Built-in timer for each player
- **Move History**: Complete move notation display
- **Position Validation**: Highlights valid moves when piece is selected
- **Undo Function**: Take back your last move

## 🚀 Quick Start

1. Open `index.html` in your web browser
2. Choose your game mode:
   - **2 Player**: Play against a friend on the same device
   - **AI**: Challenge the computer opponent
3. Click on any piece to select it
4. Click on a highlighted square to move
5. Use the undo button to take back your last move

## 🔧 Technical Details

- **Language**: Vanilla JavaScript (ES6+)
- **3D Rendering**: Three.js (inline)
- **UI Framework**: Custom CSS with modern design
- **Game Logic**: Complete chess rules implementation
- **Performance**: Optimized for smooth 60fps gameplay

## 🏆 Game Rules Implemented

- ✅ All standard piece movements
- ✅ Castling (kingside and queenside)
- ✅ En passant capture
- ✅ Pawn promotion
- ✅ Check and checkmate detection
- ✅ Stalemate detection
- ✅ Threefold repetition
- ✅ Move history with algebraic notation
